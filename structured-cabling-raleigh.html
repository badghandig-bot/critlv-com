What goes into the scope

A useful cabling quote starts with where the cable begins, where it ends and what is between those points. During the site review, we discuss the cable category, approximate distances, pathway access, terminations, labels and the required testing and documentation. Any equipment, material responsibilities or work outside the cable installation should be identified in the written proposal.

For builders and general contractors, include the latest drawings and milestones. For occupied offices, flag business hours, ceiling access restrictions and any connections that must stay online. For a home, photographs of the modem or rack, destination wall and accessible attic or crawl space help explain the project.

Our project approach

Every project is owner-scoped, technician-installed, tested, documented and owner-reviewed. The proposal defines the agreed installation and handoff, so the next person supporting the network can understand what was installed.

Questions before a cable installation

Can you add one run without rewiring the building?

We handle single runs as well as larger installations. The route and existing infrastructure need to be reviewed to determine what is practical for the location.

Should we request Cat6 or Cat6A?

Share the equipment requirements and future plans rather than selecting cable solely by its name. We can scope the cabling around those requirements and the physical installation.

Can the project include access points or cameras?

Yes. Access-point cabling, network setup and security camera installation can be discussed together. Equipment and installation responsibilities will be set out in the proposal.
