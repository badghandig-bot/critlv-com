Planning questions

Before the work starts.

Can you clean up an existing network rack?

Yes. Start with photos and a description of the problem. We review the patching, labels, equipment and connections before agreeing on a cleanup plan.

Will our network need to go offline?

Some changes can require connections to be moved or equipment to be disconnected. We discuss the impact and agree on the work window before starting; uninterrupted service should not be assumed.

Can the project include a patch panel and new cable runs?

Yes. Rack work, patch panels, jacks and new Ethernet runs can be scoped together. The proposal identifies material responsibilities and the testing and documentation required.

What information helps with a rack quote?

Send photos of the front and sides of the rack, the surrounding space, an equipment list, approximate port count and any planned additions. Tell us which connections or business hours need special coordination.
